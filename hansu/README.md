# 한수 홈페이지

`index.html` 한 파일로 된 정적 홈페이지입니다. CSS와 JS가 파일 안에 들어 있어서, 이 파일만 어느 호스팅에 올려도 그대로 열립니다. 데일리툴(`build.py`, `docs/`)과는 별개라서 데일리툴 빌드에 영향을 주지 않습니다.

## 구성

| 메뉴 | 섹션 |
|---|---|
| (첫 화면) | 메인 문구, 숫자 3개(30년+ · 83종 · 3개 업종 납품) |
| 회사소개 | 소개글, 서비스 차림표(맞춤 개발 20만 원 · OEM 150kg부터 · 표준 제품 · 신제품 개발) |
| (주방 일지) | 주방의 고민 → 한수의 해결을 한 줄씩 짝지은 표 |
| 제품 | 주력 5종, 전체 제품군(엑기스 17 · 양념·소스 38 · 시즈닝·분말 28) |
| 업종별 제안 | 식당·밀키트 / 국밥·외식 프랜차이즈 / 어묵·수산가공 / 육가공 탭 |
| 맞춤 개발 | 5단계 진행 과정, 거래 조건표 |
| 한수 이야기 | 30년 이야기, 원료가 들어가는 업종 |
| 자주 묻는 질문 | 5개 |
| 샘플 요청 | 연락처, 문의서(현재 방식·개인정보 동의 포함, 문의 글을 만들어 복사) |

머리줄과 첫 화면, 오른쪽 아래 떠 있는 버튼에 상담 전화번호가 늘 보입니다.

## 올리기 전에 바꿀 것

- **카카오톡 채널**: 채널을 만들면 `index.html` 아래쪽 스크립트의 `KAKAO_CHANNEL_URL = ""` 에 주소를 넣으면 문의 칸에 링크가 나타납니다.
- **사진**: 첫 화면만 무료 음식 사진을 넣었습니다. 공장·생산 라인·제품 사진이 준비되면 넣을 자리를 만들겠습니다.
- **거래처 이름**: 사조·진주햄 이름은 사용 허락을 받기 전이라 "대형 어묵·육가공 기업"으로만 적었습니다.
- **인증**: HACCP 등 인증 문구는 넣지 않았습니다.
- **사업자 정보**: 대표자, 사업자등록번호는 받은 자료에 없어서 하단에 넣지 않았습니다. 알려주시면 추가합니다.

## 사진

- `images/bg.jpg`: 연한 바탕 아래 흐릿하게 깔리는 해물찌개 사진(같은 출처, CC0).
- `images/hero.jpg`: 첫 화면 뚝배기 찌개 사진. rawpixel의 CC0(퍼블릭 도메인) 사진이라 출처 표시 없이 상업적으로 써도 됩니다. 한수 제품으로 만든 실제 요리 사진이 생기면 같은 이름으로 바꿔 넣으면 됩니다.
