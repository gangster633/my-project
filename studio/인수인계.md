## 2. 사용자 현재 상황 (2026-11-22 기준)

### 유튜브 채널
- 채널 이름: **세상사는 이야기**, 핸들 **@세상사는이야기**
- 방향: 매일 보지만 이유는 몰랐던 우리 주변 이야기 (지식 채널, 40대 이상 시청자)
- 올린 롱폼
  1. **동네 목욕탕이 사라지는 이유**: 약 18분, 화풍 '따뜻한 감성', 음성 Azure 현수, 17컷. 올린 지 6시간에 조회수 14였음.
  2. **요양보호사가 그만두는 핵심적인 이유**: 대본 약 6,040자 (약 20분 목표), 웹툰체, 43컷 스토리보드. 업로드 정보 JSON까지 만들었고 엔딩 화면을 넣는 중.
- 채널에 예전에 올린 다른 주제 쇼츠(의료 장면 등)가 섞여 있음 → 주제 일관성을 위해 비공개 검토를 권함.
- 채널 정보 수정(설명 저장)이 "게시" 안 되는 문제가 있었음. 원인은 확인 못 함 (시크릿 창, 다른 브라우저, 휴대폰 앱으로 시도 권함).

### 사용자가 쓰는 제작 방식 (무료 위주)
| 단계 | 방식 |
|---|---|
| 글 (대본·스토리보드·업로드 정보) | **직접 붙여넣기** 모드. 프로그램의 지시문을 Claude 채팅에 붙여 넣고 답을 다시 넣음. 최근에는 이 Claude Code 세션에 지시문을 붙여 넣어 대본을 받음. |
| 음성 | **Azure 음성 무료 등급(F0)**, 지역 `koreacentral`, 목소리 **현수**. 한 달 50만 자 무료. |
| 그림 | **무료 Gemini 앱 + 반자동 도우미** (다운로드 폴더 감시). Gemini API 키도 있지만 무료 등급이라 이미지 API는 쓰지 않음. |
| 영상·쇼츠·썸네일 | 프로그램이 PC에서 FFmpeg로 만듦 (무료). |

- Gemini API 키: 있음 (AI Studio, 결제 미연결)

- Anthropic(Claude) API 키: 없음
- 키는 사용자 PC의 `config.json`에만 있음. 채팅이나 문서에 붙여 넣지 않도록 안내함.

## 3. 영상 한 편 만드는 순서 (사용자 기준)

1. **홈**에서 주제(필요하면 기사 링크)를 넣고, 채널 성격과 분량을 정해 **영상 만들기 시작**. 원클릭 자동은 끔.
2. **대본**: **대본 생성 (지시문 복사)** → Claude에 붙여 넣기 → 답을 "직접 붙여넣기" 창이나 대본 칸에 넣음 → **대본 저장**.
   - 붙여 넣은 대본 첫 줄이 맞는지 꼭 확인. 한 번은 끝부분만 들어간 적이 있음.
3. **음성**: Azure 탭 → 현수 → **음성 생성**. 숫자 읽기가 어색하면 "숫자를 한국어로 읽기"를 끄고 비교.
4. **화풍 · 캐릭터**: 화풍 카드 선택(또는 직접 입력 화풍), 등장인물 외형(영어), 장면 길이(20~30초 권장).
5. **스토리보드**: **AI로 장면 나누기 (지시문 복사)** → Claude 답(JSON)을 넣음.
   - 지시문 자체를 넣으면 지시문 안의 예시 JSON 때문에 **장면 1개, 인물 "..."** 이 됨. Claude의 답을 넣어야 함.
6. **이미지**: 반자동 도우미 → ① 시작 지시문을 Gemini 새 채팅에 → ② 장면별 프롬프트 복사 → Gemini에서 그림 다운로드 → 자동으로 다음 장면에 들어감.
   - **"빈 장면 모두 만들기"는 누르지 않기** (자리표시 카드가 들어감).
7. **영상**: 자막 프리셋 고르고 **영상 만들기**. 1.3.4까지는 18분 영상이 1시간 넘게 걸렸음. 1.3.5에서 빨라졌는데 실제 시간은 사용자 PC에서 아직 확인 전. 진행 막대에 쓰는 인코더(CPU/NVIDIA 등)와 남은 시간이 나옴.
8. **완성**: **업로드 정보 만들기 (지시문 복사)** → 제목·설명(챕터 포함)·태그·고정 댓글·쇼츠 구간 → 썸네일 3종 → 쇼츠 → MP4 내려받기.
9. **유튜브 업로드**
   - 태그는 세부정보 → **자세히 보기** → 태그 칸에 넣기
   - "변경되거나 합성된 콘텐츠"는 **예**
   - 유료 프로모션은 체크하지 않음
   - 엔딩 화면은 "동영상 1개 + 구독", 자막을 가리지 않게 위쪽에 배치

## 4. 코드 구조

| 파일 | 역할 |
|---|---|
| `studio.py` | 로컬 웹 서버(127.0.0.1, 실행마다 바뀌는 토큰), 프로젝트 저장, 백그라운드 작업, 파일 전송(Range 지원), 반자동 도우미(다운로드 폴더 감시 스레드), 다른 버전이 켜져 있으면 끄고 새로 시작 |
| `pipeline.py` | 단계별 로직: 기사 가져오기, 대본·사실 대조·번역, 음성(문장별 합성·캐시·무음 압축·말 속도 기억), 스토리보드, 이미지, 렌더(바뀐 장면만 다시), 쇼츠, 썸네일, 업로드 정보, 편집용 묶음 |
| `ai.py` | Claude(Anthropic SDK, `claude-opus-5-5`, 거절 시 서버 측 fallback), OpenAI, Gemini 글·음성·이미지, ElevenLabs, Azure 음성, 윈도우 SAPI 음성 |
| `prompts.py` | 화풍 19종, 채널 성격, 지시문(대본·사실 대조·번역·스토리보드·업로드 정보)과 응답 해석 |
| `textutil.py` | 문장 나누기, 자막 줄 나누기, 숫자 한국어 읽기, 대본 규칙 점검 |
| `render.py` | FFmpeg 처리: 켄번즈, xfade 전환, ASS 자막(띠와 글자 별도 레이어, 숫자 강조), 배경음 덕킹, -14 LUFS, 로고, 썸네일. FFmpeg 7 이상이면 `-/filter_complex`를 쓰고, 실패하면 다른 방식으로 재시도 |
| `ui/index.html` | 화면 전체 (바닐라 JS) |
| `build_windows.py` | 윈도우 zip 빌드 (mingw 실행 파일, python.org embeddable, pip win_amd64 휠, gyan.dev FFmpeg) |
| `.github/workflows/build-studio.yml` | push 때 모듈 점검과 zip 빌드 |

```bash

```

이 명령은 토큰을 출력합니다. API를 부를 때는 `X-Token` 헤더에 그 토큰을 넣습니다.

## 6. 알려진 문제와 주의

**아직 실제로 확인하지 못한 것**
- 실제 API로는 다음을 확인하지 못했어요. 요청 형식만 가짜 서버로 확인했어요.
  - Claude, Gemini 이미지·음성, OpenAI, ElevenLabs
- 윈도우 실제 환경은 사용자가 쓰면서 확인 중이에요.
  - Azure 음성(현수)은 동작이 확인됐어요.
  - 영상 합치기는 1.3.3 이후 다시 시도한 결과를 아직 못 받았어요.

**알려진 문제**
- (1.3.4에서 고침) 지시문 복사가 가끔 안 되던 문제, 스토리보드에 지시문을 붙여 넣으면 1컷이 되던 문제. 윈도우 실제 환경에서는 아직 확인 전.

- 영상 만들기 속도 (1.3.5): 리눅스 4코어 측정으로 최종 합치기 1.5배(CPU만 쓸 때). 그래픽카드 인코더는 여기서 시험할 수 없어서 윈도우에서 확인해야 함. 되는지 1프레임 시험 후 쓰고, 도중에 실패하면 CPU로 다시 만듦.

**사용자가 자주 헷갈린 것**
- 드롭다운 안에 숨은 "직접 붙여넣기" 선택지
- 대본을 붙여 넣는 위치 (두 번째 상자)
- 새 zip을 풀어도 옛 버전이 열리던 문제 (1.3.3에서 해결)

**무료 등급의 한계**
- Gemini 무료 등급: 하루 요청 수가 적어요. 이미지 API는 막혀 있을 가능성이 높아요.
- Azure F0: 동시 요청이 적어서 프로그램이 2개씩만 보내요.

**유튜브**
- 그림이 20장 이상인 형식은 무료 Gemini 앱의 하루 생성 한도에 걸릴 수 있어요.
- Gemini 무료 그림에는 작은 표시가 들어갈 수 있어요.

## 7. 콘텐츠 원칙 (지금까지 지켜 온 것)

- 대본의 숫자는 **언론 보도로 확인한 것만** 쓰고, 영상 첫머리에 출처와 한계를 한 문장으로 밝힌다.
- 확인된 자료가 모자라면 분량을 억지로 채우지 않는다. 대신 기사를 더 찾아 참고 자료에 넣는다.
- 의견·전망은 "~라는 분석도 있어요"처럼 사실과 구분한다.
- 남의 영상·대본을 베끼지 않는다. 그림체와 구성만 참고한다. 재사용 콘텐츠 정책 때문이다.
- 업로드할 때 "변경되거나 합성된 콘텐츠"는 **예**로 표시한다. 채널 설명에도 AI 활용을 안내한다.
- 구글 계정 여러 개 돌려쓰기, 무료 웹 서비스(Gemini 앱 등) 자동 조작, 워터마크 제거는 하지 않는다.
