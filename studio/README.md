# AI 영상 공방 (윈도우 프로그램)

기사 링크나 주제 하나로 유튜브 롱폼 영상, 쇼츠, 썸네일, 제목·설명·태그까지 만드는 PC 프로그램입니다.
내 PC에서 작은 웹 서버(127.0.0.1)를 띄우고 브라우저로 화면을 엽니다. API 키와 프로젝트는 그 PC의 `%APPDATA%\VideoWorkshop`에만 저장됩니다.

## 제작 흐름

| 단계 | 하는 일 |
|---|---|
| 대본 | 기사 본문 가져오기, 분량(분/글자)·채널 성격·구독 부탁 위치에 맞춘 대본, 규칙 점검, **자료와 사실 대조**, 일본어·영어 번역 |
| 음성 | 윈도우 기본 음성(무료)·Gemini·OpenAI·ElevenLabs, 미리듣기·즐겨찾기, **숫자 자동 한국어 읽기**, 발음 사전, 무음 압축, 고친 문장만 다시 합성, 음성별 실제 말 속도를 기억해 다음 대본 분량 보정 |
| 화풍 | 16종 + 직접 입력, **고정 인물 설명**을 모든 장면에 넣어 얼굴·옷차림 유지 |
| 스토리보드 | AI가 문장을 장면으로 묶고 그림 프롬프트·카메라 움직임·전환을 정함. 장면 나누기·합치기·수정 |
| 이미지 | Gemini·OpenAI로 일괄 생성(동시 요청), 장면별 재생성, 다른 사이트 그림·영상 클립 끌어다 놓기, 프롬프트 일괄 복사 |
| 영상 | 켄번즈·줌·이동, 50가지 가까운 전환 중 장면별 배정, 숫자 강조 자막(ASS), 자막 프리셋 8종·실시간 미리보기, 로고 드래그 배치, 배경음 자동 덕킹, 유튜브 음량(-14 LUFS), **바뀐 장면만 다시 렌더링**, 다국어 버전 |
| 완성 | 세로 쇼츠(흐린 배경 + 제목), 썸네일 3종, 제목 5개·챕터 포함 설명·태그·고정 댓글, SRT, 캡컷·프리미어용 묶음(zip), 업로드 전 확인 목록 |

키가 하나도 없어도 쓸 수 있습니다. 글 AI를 "직접 붙여넣기"로 두면 지시문을 복사해 Claude.ai·ChatGPT 같은 채팅에 넣고, 받은 답을 다시 붙여 넣습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `studio.py` | 서버, 프로젝트 저장, 백그라운드 작업, 파일 전송(Range 지원) |
| `pipeline.py` | 단계별 제작 로직 |
| `ai.py` | Claude(Anthropic SDK)·OpenAI·Gemini·ElevenLabs·윈도우 음성 연결 |
| `prompts.py` | 화풍 16종, 채널 성격, AI 지시문과 응답 해석 |
| `textutil.py` | 문장 나누기, 자막 줄 나누기, 숫자 읽기, 대본 점검 |
| `render.py` | FFmpeg: 음성 다듬기, 장면 클립, 전환, 자막, 덕킹, 썸네일 |
| `ui/index.html` | 화면 |
| `windows/launcher.c` | 더블클릭용 실행 파일 |
| `build_windows.py` | 윈도우 배포 zip 만들기 |

## 개발 중 실행 (파이썬 3.10+, ffmpeg 필요)

```bash
pip install anthropic
python3 studio/studio.py
```

## 윈도우 배포 파일 만들기 (리눅스에서)

```bash
sudo apt install gcc-mingw-w64-x86-64
pip install pillow
python3 studio/build_windows.py
```

결과: `studio/dist/AI영상공방-<버전>-windows.zip` (포터블 파이썬, anthropic SDK, FFmpeg 포함, 약 95MB).
GitHub Actions의 "AI 영상 공방 빌드" 워크플로를 실행해도 같은 zip이 아티팩트로 만들어집니다.

## 보안

- 서버는 127.0.0.1 에만 열리고, Host 헤더와 실행마다 바뀌는 토큰을 확인합니다.
- 파일 전송은 프로젝트 폴더 밖을 읽지 못하게 막습니다.
- API 키는 해당 AI 회사로만 보냅니다.
