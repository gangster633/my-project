키워드 수집

씨앗 키워드를 넣으면 네이버가 씨앗 하나당 연관 키워드를 수백 개까지 돌려줍니다. 매일 수집하면 트렌드가 최신으로 유지됩니다.

대기 중
알아 두세요
  • 블로그 문서 수와 30일 트렌드는 NAVER API HUB 키가 있어야 받습니다. 앱에 블로그 검색과 데이터랩(검색어 트렌드)을 모두 추가하세요.
  • 일 검색량은 월간 검색수를 데이터랩 일별 비율로 나눈 추정값입니다. 트렌드가 없으면 월간 검색수 ÷ 30으로 표시합니다.
  • 수집한 데이터는 이 PC에만 저장됩니다.
설정

API 설정

네이버에서 무료로 받은 내 API 키를 넣습니다. 키는 이 PC에만 저장되고 다른 곳으로 보내지지 않습니다.

네이버 검색광고 API (필수 · 검색량)

searchad.naver.com → 도구 → API 사용 관리

NAVER API HUB (선택 · 블로그 문서 수 + 30일 트렌드)

ncloud.com 콘솔 → NAVER API HUB → Application 등록(블로그 검색, 데이터랩 검색어 트렌드 선택) → 인증 정보
