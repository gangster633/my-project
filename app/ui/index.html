키워드 수집

씨앗 키워드를 넣으면 네이버가 연관 키워드를 씨앗 하나당 수백 개까지 돌려줍니다. 같은 키워드를 매일 수집하면 전일·7일 대비 변화가 계산됩니다.

대기 중
알아 두세요
  • 블로그 문서 수는 네이버 검색 API 키가 있어야 셉니다. 하루 25,000회까지 무료입니다.
  • 문서 수가 없으면 황금지수도 비어 있고, 검색량만 보입니다.
  • 수집한 데이터는 이 PC에만 저장됩니다.

API 설정

네이버에서 무료로 받은 내 API 키를 넣습니다. 키는 이 PC에만 저장되고 다른 곳으로 보내지지 않습니다.

네이버 검색광고 API (필수)

searchad.naver.com → 도구 → API 사용 관리

NAVER API HUB 블로그 검색 (선택 · 블로그 문서 수)

ncloud.com 콘솔 → NAVER API HUB → Application 등록(블로그 검색 선택) → 인증 정보
